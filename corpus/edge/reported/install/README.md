# Four tools that answered confidently and wrongly

Every file here is a transcript or an artefact shape from a filed, reproduced issue. The
three version files disagree with each other simultaneously, which is the condition
claude-code#72616 describes: `lastUpdated` advanced while the cached manifest and the
installed record named different versions, and the stale view survived until the file was
overwritten by hand.

The shared lesson is the one worth planting: a command's success string is not a
postcondition. Only reading back what it claims to have written is.
