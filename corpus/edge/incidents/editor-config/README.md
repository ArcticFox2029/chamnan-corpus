# Two campaigns and one shape

**MaliciousCorgi**, January 2026: two extensions sold as AI coding assistants, 1.5 million
combined installs, capturing every file opened and every modification and sending them to
servers the user never chose. The extensions worked. That is why they lasted.

**TeamPCP**, May 2026: a poisoned Nx Console extension, live on the marketplace for
**eighteen minutes**, long enough to reach a GitHub employee's device and clone roughly
3,800 internal repositories. Eighteen minutes is the number worth keeping: a review
cadence measured in days does not intersect it.

`extensions.json` here recommends both campaigns' identifiers beside two real ones.
