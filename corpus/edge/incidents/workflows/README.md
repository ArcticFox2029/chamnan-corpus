# Three workflows, each valid YAML and each a different way in

`pull_request_target` with a head checkout runs a stranger's code with the repository's
secrets. A mutable tag is a pointer, and the March 2025 tj-actions/changed-files
compromise moved the tags to a commit that dumped runner memory into public build logs.
An event title interpolated into `run:` is a shell injection whose payload is a sentence
somebody typed into a web form.

None of the three is malformed. A linter passes all of them.
