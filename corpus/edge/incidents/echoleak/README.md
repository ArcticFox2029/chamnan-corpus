# Eight places that carry text into a reader without appearing in the document

Speaker notes, a frontmatter field, alt text, a link title, a comment inside a cell, SVG
metadata, a schema description, a commit trailer. Every one is a legitimate field with a
legitimate purpose, which is why stripping them is not an option and reading them as
instructions is not one either.
