# One workspace, several people, and files nobody edits by hand

The workspace is committed so a team shares one accumulated memory. Everything here
follows from that: merge markers inside the file the block quotes, machine-specific
absolute paths in generated state, two releases writing one format, a CI job that
fails on the tool's own writes, and two timezones disagreeing about what today is.

A correct answer does not require the team to stop committing the workspace. It
requires the tool to notice: conflict markers in its own input, a path that names
somebody's home directory, and a record written by a release that is not this one.
