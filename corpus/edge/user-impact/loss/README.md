# What the sweeps take, that a rebuild cannot give back

A retention window shorter than the gap between a failure and somebody looking at
it, a hand-written procedure used four times a year, one file governed by two
policies in two units, and a state section that is old by the calendar and current
by the work.

A correct answer is not longer retention. It is that anything deleted was either
rebuildable or named to the user first.
