# Installed, and producing nothing that says so

A workspace with no hook to deliver it, a `.version` written by a different install
than the one running, a registered command pointing at somebody else's home
directory, an index that names files renamed months ago, and a config with every
surface off.

All five look identical from the user's side: they installed it, and their sessions
are the same as before. A correct answer distinguishes 'nothing to say' from 'not
running' -- which is the distinction this corpus asks for everywhere else too.
