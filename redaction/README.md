# The redaction corpus — the format, and the rule that keeps it safe to hold

The inline table in `tools/redactor_recall.py` is 147 hand-written cases and the package's own
known limitation says so: **99% is a figure about that fixture, not a guarantee about anybody's
repository.** This directory is where the corpus grows past it without the file becoming the most
dangerous one in the tree.

## One case per line, in `cases.jsonl`

| field | required | what it is |
|---|---|---|
| `id` | yes | stable, unique, kebab-case. It is quoted in findings, so it must not be renumbered |
| `text` | yes | the line or block the redactor is given |
| `secret` | no | the substring that MUST be redacted. **Absent means benign** — the text must survive untouched |
| `source` | yes | `synthetic` · `sanitized` · `fuzz` — see below |
| `why` | yes | one sentence: what shape this case is, and what would miss it |
| `near` | no | the `id` of the benign case that looks most like this one |

## A key-shaped value is stored in parts

`text` and `secret` may be a JSON list of strings instead of one string; the case is the
strings joined. Every value shaped like a provider's credential is stored that way, so no
scanner — GitHub push protection included, which also decodes base64 — ever sees it whole,
while the reader hands the redactor exactly the original string. The readers here
(`check.py`, `recall.py` and `chamnan_checks/`) join the parts; a new reader must too.

## The three sources, and why they are not one set

- **`synthetic`** — written to exercise a shape. Cheap, complete, and it only ever contains what
  somebody already thought of. That is the ceiling the 20 cases here and the 147
  strings in `recall.py`'s tables (99 shapes, 48 ordinary neighbours) sit at.
- **`sanitized`** — taken from a real repository, with every credential replaced. This is the set
  that finds shapes nobody would invent, and the only one that can say anything about real code.
- **`fuzz`** — generated by mutating a case: change the alphabet, the length, the separator, the
  surrounding punctuation. Finds the boundary of a rule rather than its centre.

A recall figure over all three is a different claim from a figure over one, and reporting them
separately is what stops the easy set flattering the hard one.

## 🔴 The rule: nothing here is ever a live credential

A corpus of secrets stored in a public repository is a leak with a test suite attached. So:

1. **Every `secret` value is provably fake.** It uses the filler convention the inline table
   already uses, or a character run no issuer produces. A case whose secret could be real does not
   go in — it goes in the commit message of the fix, redacted, and nowhere else.
2. **Sanitizing is replacement, not truncation.** A truncated key still identifies its owner and
   still tells an attacker the prefix. The replacement keeps the SHAPE and none of the value.
3. **Provenance names a repository, never a person and never a URL with a token in it.**
4. **`chamnan-guard` runs over this directory like any other** — the corpus is not exempt from the
   check it exists to improve, and a case that trips it is a case that was sanitized wrong.

## What a benign near-neighbour is for

A detector is only as good as what it leaves alone. Every shape added here should come with the
closest thing that is NOT a secret — a commit hash beside an API key, a base64 image blob beside a
token, a UUID beside a session id. Precision is measured on those, and a rule that cannot tell a
pair apart is a rule that will damage real code.

Recorded because it has happened: false positives here have destroyed GraphQL documents, Swift and
Dart `Codable` blocks, SQL, Lua and Protobuf. Recall is not the only number.

## What else lives here, and how it runs

- **`recall.py`** — the recall and precision benchmark for chamnan's redactor, moved here from
  chamnan's `tools/` on 2026-09-24 with its tables of synthetic key shapes. chamnan's README
  credits its published figures to it. Run it against a chamnan checkout:
  `python3 redaction/recall.py --chamnan <path to chamnan>` (or set `CHAMNAN_PLUGIN`; a checkout
  beside this corpus is found on its own).
- **`chamnan_checks/`** — the checks from chamnan's suite that need a key shape, and the ones that
  hold chamnan's published redaction figures to this benchmark. They use chamnan's suite preamble
  and run in chamnan's release step against the corpus, never in chamnan's own suite or CI.
- **`check.py`** — holds `cases.jsonl` to the contract above.
